About Me

I am Miguel Badayos, a Software Engineer who has been building full-stack web applications at Radical Systems since April 2026, working with ASP.NET Core, C#, and SQL Server on the backend and Vue.js with TypeScript on the frontend. I have just finished the final semester of my Bachelor of Software Engineering Honours at Charles Darwin University. Fascinated by technology and engineering from a young age, I began coding in 2022 during high school. I enjoy developing software that serves a purpose, whether for myself or others, and find satisfaction in solving problems through code. Outside of work, I also love creating fun and interesting personal projects, making coding both my career and a hobby.

Technologies Used

These are the technologies I commonly use or had long experience with for development since the starting my coding journey.

Python

Python is a dynamically typed language known for its ease of use, which I have used for terminal apps and Django web apps like Thesys.

JavaScript

JavaScript is another dynamically typed language and now the one I am most comfortable with, helping me make interactive websites.

TypeScript

TypeScript is a superset of JavaScript, having additional features like static typing which improves my developer experience.

C# / .NET

C# with ASP.NET Core is what I use at work for backend development, building on the .NET MVC experience I gained making Easy Games.

Vue.js

Vue.js is a frontend framework I use professionally alongside TypeScript to build responsive features for production web apps.

SQL Server

SQL Server is a relational database that I use alongside C# and ASP.NET Core to develop the backend of production applications.

Go

Go has great built-in libraries like the HTTP library and great performance, powering the backends of Cozy Park and Times I Pooped.

Cloudflare

Cloudflare is a cloud platform that offers various services like Cloudflare Pages, my go-to way to host serverless websites for free.

Docker

Docker is a tool that allows software to be containerised, ensuring that the software runs consistently accross multiple devices.

Git

As someone who creates multiple copies for each version before learning Git, it has made developing more convenient especially in a groupwork.

Arch Linux

I do not usually say this but, I use Arch btw. Linux in general is a great operating system especially for development due to the CLI tools built on it.

Neovim

Neovim is a text editor in the terminal that have a great ecosystem. It has helped me enjoy coding 10x more and made me code faster through its Vim Motions.
